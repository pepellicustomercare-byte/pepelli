# 🌸 Pepelli — AI-Powered Ethnic Fashion E-Commerce Website

An exact, high-fidelity recreation of the **Pepelli** ethnic fashion e-commerce storefront, supercharged with modern **AI Fashion Technology** and full interactive shopping capabilities.

### 2. 🤖 Cutting-Edge AI Features
1. **Pepelli AI Personal Stylist (`ai-stylist.js`)**:
   - Floating `✨ Ask AI Stylist` pulsating badge.
   - Intelligent chatbot trained in Indian ethnic fashion styling (Weddings, Sangeet, Office Wear, Summer Cottons, Color Harmony, Jewelry pairing).
   - Recommends matching catalog products directly inside chat with one-click Add to Cart.
2. **Pepelli AI Virtual Mirror & Try-On Studio**:
   - Mannequin skin tone switcher (Fair, Wheatish, Dusky Warm).
   - Live canvas garment overlay with adjustable scale, fabric drape blend, and silhouette alignment.
   - Calculates **AI Fit Flattering Score** (e.g. *98% Match*).
3. **AI Smart Size & Fit Advisor**:
   - 4-point measurement predictor (Height, Weight, Bust, Silhouette Preference).
   - Computes recommended size (S, M, L, XL, XXL) with percentage match confidence and fabric ease guidance.
4. **AI Visual Search & Image Matcher**:
   - Camera button in the top search pill.
   - Upload any photo or Instagram screenshot to find matching Pepelli kurtis.

### 3. 🛍️ Full E-Commerce Store Engine (`app.js`)
- **Cart Drawer**:
  - Slide-out panel with item quantities (+/-), size tags, and delete buttons.
  - **Free Shipping Progress Bar** (Spend ₹201 more for Free Delivery!).
  - Coupon Code Engine (`PEPELLI10` for 10% off, `FIRST150` for ₹150 off).
  - One-click checkout & WhatsApp order integration.
- **Wishlist Drawer**: Save favorites with heart toggle and move to cart anytime.
- **Product Details & Quick View Modal**:
  - High-res photo preview, size selection, fabric specifications, and stock scarcity indicators.
- **Track Order System**:
  - Live animated tracking timeline from *Order Confirmed* to *Delivered*.
- **Multi-Step Checkout & Confetti Celebration**:
  - Delivery address form, COD / UPI payment options, and confetti animation upon completion with official order ID.
- **Instant WhatsApp Ordering**:
  - Pre-formats order details into ready-to-send WhatsApp messages to `wa.me`.

## 🚀 How to Run Locally

### Option 1: Double-Click Launcher
Simply double-click `start_website.bat` in the workspace folder. It will start the server and open `http://localhost:3000` automatically.

### Option 2: Command Line
```powershell
& "C:\Users\plli4\AppData\Roaming\Antigravity\bin\agy-node.cmd" server.js
```
Then visit **`http://localhost:3000`** in your browser.

### Option 3: Direct File View
You can also open `index.html` directly in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
